# Claude Code adapter

@AGENTS.md

Канонические инструкции — AGENTS.md (импортирован выше). Затем прочитай
[docs/current/START_HERE.md](docs/current/START_HERE.md).
Репозиторные skills находятся в корневом каталоге `skills/` и не считаются
автоматически загруженными только потому, что присутствуют в репозитории. Перед
специализированной задачей Claude Code вручную открывает релевантный
`skills/<skill-name>/SKILL.md` и применяет его вместе с `AGENTS.md`, актуальной
документацией репозитория, фактическими кодом и тестами; при расхождении
состояние репозитория важнее предположений skill.

Этот файл не определяет отдельную архитектуру или отдельные правила. При любом
расхождении верны фактический код, Git и `AGENTS.md`.
