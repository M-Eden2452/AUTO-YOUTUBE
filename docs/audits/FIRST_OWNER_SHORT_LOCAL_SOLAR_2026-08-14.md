## 5. Root cause — доказан

### 5.1 Коарс-поиск не видит кириллицу (BLOCKER)

`src/media_library.py:580`:

```python
def _tokens(value: Any) -> list[str]:
    ...
    tokens.extend(part for part in re.split(r"[^a-zA-Z0-9]+", str(item).lower()) if part)
```

Класс символов — только латиница и цифры, поэтому каждая кириллическая буква
является разделителем:

```
_tokens(['панель ловит Солнечная']) == []
_tokens(['солнечная панель'])       == []
_tokens(['solar panel'])            == ['solar', 'panel']
```

Следствие в `_score_asset` (`:534`): `keyword_hits` для русского запроса пуст
всегда и у всех. Единственные набранные очки — `type` (+1), `aspect_16_9` (+1),
`duration` (+1) = 3 у каждого горизонтального видео. `search_local_assets`
(`:92`) сортирует по `(score, duration)` — при полном равенстве очков остаётся
сортировка по длительности, и `limit=10` отрезает десять самых длинных клипов
библиотеки. Запрос на выбор не влияет вообще.

Тот же матчер, тот же индекс, английский запрос:

| Запрос | Топ выдачи | Очки |
|---|---|---|
| `solar panel photovoltaic` | `pexels_9788590` (крупный план ячеек) | 12 |
| | `pexels_27009031`, `pexels_32386564`, `pexels_13198260` | 9 |
| `battery storage energy` | `pexels_36167827` (стойка аккумуляторов) | 12 |
| `factory conveyor assembly` | `pexels_32386564` (конвейер сборки панелей) | 12 |
| `wind turbines sunset` | `pixabay_307864` (ветряк на закате, вертикальный) | 11 |
| `rainforest canopy jungle` | 5 клипов полога тропического леса | 12 |

То есть покрытие есть, матчер исправен, метаданные (в том числе русские
`keywords_ru`, добавленные курацией) корректны — русский вход просто не доходит
до сравнения.

### 5.2 Вертикальные клипы структурно не попадают в шортлист

`aspect_16_9` (+1) выдаётся только горизонтали. При нулевых keyword-хитах это
даёт 3 у 80 горизонтальных видео против 2 у всех 4 вертикальных, поэтому для
Short 9:16 родные вертикальные исходники **никогда** не входят в top-10.
Проверено: `score=3: 80 items, vertical=0` / `score=2: 5 items, vertical=4`.
При настоящих keyword-хитах вертикаль конкурирует нормально (`pixabay_307864`,
11 очков на английском запросе) — дефект проявляется именно вместе с §5.1.

### 5.3 Русская морфология на семантическом слое (второй порядок)

Даже дойдя до ranker, правильный клип может получить `subject_match=0`.
`pexels_14067718` против сцены 2 (`subject: панель`), evidence-токены записи
содержат `панели`, `панелей`, `солнечные`, `солнечных`, `ряды`, `аэросъёмка`:

| термин | literal score | stem_match |
|---|---|---|
| `панель` | **0.0** | **False** |
| `панели` | 100.0 | True |
| `панелей` | 100.0 | True |
| `солнечная` | **0.0** | **False** |
| `солнечных` | 100.0 | True |

`stem_match` (`src/assets/semantic_selection/evidence.py:181`) допускает только
префиксное отношение, а русское склонение меняет хвост, а не дописывает его:
`панель` и `панели` расходятся на шестом символе. Планировщик же выбирает
**самую короткую** встреченную форму (`entities.py:214`), то есть ровно
номинатив — форму, которой в описании ассета может не быть. Отсюда `semantic
score 23.529` и `mismatched` у клипа, который буквально показывает предмет сцены.

Этот дефект не является причиной провала прогона (до ranker правильные кандидаты
не дошли), но он остаётся вторым барьером после исправления §5.1.
