# Adaptive story_card_short_v1 — Layout Report (v1 → v2)

Этап 1 из `docs/handoff/NEXT_PLAN.md`: единственный фирменный `story_card_short_v1`
сделан адаптивным. Сова перерендерена бесплатно (без поиска, Vision, TTS и скачиваний)
в `projects/story_card_owl_test/final_test_v2.mp4`. Первая версия не изменялась.

## Что изменилось в подходе

- Раньше `central_video` имел фиксированные `x/y/width/height`, а `video_y` был жёстко
  задан в preset. Из-за этого между верхним текстом и видео и под комментарием оставались
  большие пустые зоны, а видео было маленьким.
- Теперь `build_story_card_layout` **измеряет реальную высоту** верхнего текста, блока
  канала и нижнего комментария (`_measure_wrapped_block`, повторяет вертикальный шаг
  функций отрисовки, поэтому текст не обрезается), а затем:
  - ставит комментарий близко к нижнему краю карточки;
  - блок канала — сразу над комментарием;
  - верхний текст — у верхнего края;
  - всё свободное пространство отдаёт центральному видео.
- Высота видео ограничена только **head-safe** соотношением сторон (`min_video_aspect = 1.18`),
  чтобы центр-кроп горизонтального исходника 1920×1080 **не резал голову и глаза совы**.
  Предел проверен визуально на кадрах анфас (оба «ушка» и оба глаза в кадре) и профиль.
- Исходник не растягивается: используется равномерный `_fit_cover` (масштаб + центр-кроп),
  пропорции сохраняются.
- Одна фирменная структура сохранена: верхний текст → центральное видео → блок канала →
  нижний комментарий. Тёмная карточка, размытый/затемнённый фон, скруглённые углы,
  цветовая система, «Пульс природы», `@nature_pulse_test` и тексты не менялись.
  Размеры шрифтов умеренно увеличены (лучше читаемость на вертикальном Shorts и заполнение
  карточки): top 38→46, comment 30→36, brand 34→40, username 24→26.

## Заполнение карточки и пустые зоны

Полезная область = высота карточки минус верхний и нижний отступ
(`top_pad = 54`, `bottom_pad = 44`), одинаково для обеих версий: **1630 px**.
Content = сумма высот верхнего текста + видео + блока канала + комментария.

| Метрика | v1 | v2 |
|---|---|---|
| top_text_height | 306 | 466 |
| пустое пространство сверху (текст → видео) | ~260 px | **26 px** |
| bottom_gap (низ комментария → низ карточки) | ~251 px | **44 px** |
| unused_vertical_space (сумма зазоров в полезной области) | ~572 px | **185 px** |
| content_occupancy_ratio | ~0.65 | **0.887** |

Целевой `content_occupancy_ratio ≥ 0.88` достигнут: **0.887**.
Остаточные 185 px «unused» — это head-safe запас: видео нельзя сделать выше 772 px
без обрезки головы совы, поэтому небольшой зазор остаётся между видео и блоком канала.
