# Architecture Decision Records

ADR фиксируют решения, которые меняют публичные контракты или архитектурные границы.
Код и Git имеют приоритет над ADR.

Имена: `NNNN-short-title.md`. Обязательные разделы:

- Status
- Context
- Decision
- Consequences
- Verification

Не редактируй принятый ADR так, будто прошлое решение было другим. Создай новый ADR,
который заменяет старый.
