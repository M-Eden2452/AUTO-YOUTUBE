# Anime Factory

## Назначение

Anime Factory готовит короткие клипы из локальных anime-видео: ищет кандидаты, анализирует звук/сцены, делает динамический кроп и собирает preview или выбранные шорты.

## Как работает

Точка входа находится в `anime_factory/pipeline.py`. Пайплайн принимает локальный видеофайл, извлекает аудио, может использовать транскрибацию, скоринг кандидатов, уточнение границ, субтитры, динамический кроп и рендер клипов.

## Основные файлы

- `anime_factory/pipeline.py` - CLI режима.
- `anime_factory/paths.py` - структура output-папок.
- `anime_factory/ffmpeg_utils.py` - обертки над FFmpeg.
- `anime_factory/extract_audio.py` - извлечение аудио.
- `anime_factory/transcribe.py` - транскрибация.
- `anime_factory/score_candidates.py` - оценка клипов.
- `anime_factory/dynamic_crop.py` - вертикальное кадрирование.
- `anime_factory/render_clips.py` - финальная сборка.
